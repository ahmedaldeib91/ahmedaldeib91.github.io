# مركز الدورة (المرحلة 1 من إعادة تنسيق لوحة المدير)

الدورات ← اختيار دورة ← تبويبات تخص تلك الدورة وحدها (`#courses/<id>/<قسم>`):

| التبويب | المحتوى |
|---|---|
| الاشتراكات | مشتركو الدورة: إضافة بالبحث وإلغاء (نفس وحدة الاشتراكات العامة مع تثبيت الدورة) |
| الملفات / الفيديوهات | كما كانت |
| الأسئلة | أقسام فرعية: بنك الأسئلة، المجلدات (مجال ← موضوع ← موضوع فرعي)، الفريق، الأسئلة السريعة (أسئلة المحاكاة الحالية في لوحة المتدرب) |
| الاختبارات | قائمة اختبارات الدورة وسير النشر |
| المجموعات | حجز مكان: تُبنى في المرحلة 3 |

- القائمة الجانبية: أُزيلت «الاشتراكات» و«بنك الأسئلة» و«الاختبارات» (صارت داخل الدورة). مساراتها القديمة تحوّل تلقائيًا إلى مركز الدورة، ومحررا السؤال والاختبار يبقيان صفحتين كاملتين (`#qbank/<c>/new|edit|copy` و`#exams/<c>/new|edit`) وزر الرجوع فيهما يعود للمركز.
- لا تغيير في قاعدة البيانات.

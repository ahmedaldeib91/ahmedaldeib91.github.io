# LMS المرحلة 2 — استيراد وتصدير الأسئلة

لا ترحيل قاعدة بيانات في هذه المرحلة: الاستيراد يمر بالدالة الموجودة `qb_save_question` نفسها (نفس التحقق ونفس الصلاحيات وحدّ ١٢٠ حفظًا في الدقيقة).

## الواجهة
تبويب «الأسئلة» في مركز الدورة ← زرّان جديدان: **استيراد** و**تصدير** (بنك كل دورة منفصل كما كان).
- **الاستيراد:** اختيار الملف (حتى ٢ ميغابايت و٥٠٠ سؤال) ← تحديد الصيغة تلقائيًا أو يدويًا ← «تحليل ومعاينة» (جاهز / جاهز مع تنبيه / خطأ مع السبب لكل سؤال)
  ← «استيراد الصالح فقط» ← تقرير نهائي (عدد المستورد، المكرر بالمحتوى، ما فشل وسببه). الصالح لا يُفقد بسبب غير الصالح.
  خيارات: المجلد المستهدف، الحالة (مسودة افتراضيًا)، الصعوبة الافتراضية. قالب CSV للتحميل.
- **التصدير:** الصيغة (GIFT / Moodle XML / Aiken / CSV) + تصفية بالحالة والمجلد. الأنواع غير المدعومة في الصيغة تُعدّ في الرسالة.

## الصيغ
| الصيغة | الاستيراد | التصدير |
|---|---|---|
| Aiken | اختيار واحد (وأكثر من إجابة تُحوَّل إلى اختيار متعدد مع تنبيه) | اختيار واحد وصح/خطأ |
| GIFT | اختيار (واحد/متعدد بالأوزان)، صح/خطأ، مطابقة، ملاحظات الخيارات و`####` الشرح العام، `::عنوان::`، الهروب `\:` `\=` إلخ | الأنواع الأربعة |
| Moodle XML | multichoice وtruefalse وmatching؛ HTML يتحول إلى نص | الأنواع الأربعة |
| CSV | الأعمدة type, question, option_a.., correct, explanation, feedback_*, points, difficulty, status (فاصلة أو فاصلة منقوطة أو Tab، UTF-8) | الأنواع الأربعة (حتى ٦ خيارات) |
Excel: احفظه كـ CSV UTF-8 (لا قراءة مباشرة لـ xlsx حاليًا).

## ما لا يُستورد (يظهر في التقرير برسالة صريحة، لا يُهمل بصمت)
إجابة قصيرة، مقالي، رقمي، Cloze/ملء الفراغات، ترتيب، سحب وإفلات، محسوب، نص وصفي. الصور داخل HTML لا تُستورد (تنبيه).
هذه الأنواع تحتاج أنواعًا جديدة في سجل الأسئلة (ترحيل قاعدة بيانات + مصحّح): المرحلة 2ب.

## حدود
- الأوزان الجزئية في GIFT/Moodle تتحول إلى «تصحيح جزئي» دون حفظ القيم الدقيقة للأوزان.
- ترميز الملف يجب أن يكون UTF-8 (تنبيه عند اكتشاف حروف مشوّهة).
- لا يوجد تراجع لدفعة استيراد كاملة بنقرة؛ الأسئلة المستوردة مسودات ويمكن حذفها/تعطيلها من القائمة.

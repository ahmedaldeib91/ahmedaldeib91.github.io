# LMS المرحلة 2ب — أنواع أسئلة جديدة + التصحيح اليدوي

## الأنواع الخمسة
| النوع | المتدرب يرى | التصحيح |
|---|---|---|
| إجابة قصيرة (short_answer) | خانة نص | آلي: مطابقة بعد توحيد (همزات، تشكيل، تاء مربوطة، أرقام، مسافات) مع أي إجابة مقبولة؛ اختياريًا مطابقة حالة الأحرف |
| رقمي (numerical) | خانة رقم + وحدة | آلي: القيمة ± هامش (مطلق أو نسبة)، يقبل الأرقام العربية و«٫» |
| مقالي (essay) | مربع نص + عدّاد كلمات | يدوي بواسطة المدرب |
| ترتيب (ordering) | قائمة تُرتَّب بأزرار الأسهم (تُعرض مخلوطة دائمًا) | آلي: كله أو لا شيء / جزئي بحسب الأماكن الصحيحة |
| ملء الفراغات (fill_blank) | الجملة بخانات مضمَّنة | آلي لكل فراغ؛ كله أو لا شيء / جزئي |
(ملء الفراغات بقوائم منسدلة «Cloze» ما زال مسجَّلًا كنوع غير مفعّل.)

## قاعدة البيانات (017 + 018 + 019، تُطبَّق معًا)
- 017: مدقّقات كل نوع (تمنع تسرّب الإجابة إلى الحمولة العامة) + تفعيلها في سجل الأنواع (+ النوع الجديد fill_blank).
- 018: الاستبدال الداخلي لدوال المحاولات (خريطة الخيارات، فحص الإجابة، المصحّح الآلي، ما يراه المتدرب) مع الحفاظ على سلوك الأنواع القديمة.
- 019: حالة التصحيح للمحاولة (`grading_status`) ولكل سؤال (`manual`, المصحّح، الملاحظة)، وثلاث دوال للمصحّح بصلاحية `grading`:
  `exam_grading_queue` و`exam_grading_get` و`exam_grade_item`. المحاولة التي فيها مقال مُجاب تبقى «بانتظار التصحيح» ولا يرى المتدرب درجتها ولا مراجعتها
  حتى تُصحَّح كل المقالات، ثم تُحسب الدرجة والنتيجة تلقائيًا. يمكن تعديل درجة مقال بعد الاكتمال (تُعاد الحسبة). مقال بلا إجابة = صفر تلقائيًا.
- التراجع: `docs/lms/rollback-017-019.sql`.

## الواجهة
- **محرر بنك الأسئلة:** الأنواع الخمسة في قائمة النوع بحقولها (إدراج فراغ بزر، ترتيب العناصر بالأسهم، هامش القبول…) مع معاينة بشكل المتدرب.
- **بوابة المتدرب:** عرض كل نوع في الاختبار + مراجعة النتيجة؛ رسالة «بانتظار التصحيح» حين توجد مقالات غير مصحّحة.
- **لوحة المدير:** تبويب جديد «التصحيح» في مركز الدورة: قائمة الانتظار ← صفحة المحاولة (إجابة المتدرب + المعيار والإجابة النموذجية + الدرجة والملاحظة).
- **الاستيراد/التصدير:** GIFT (قصير، رقمي، مقالي) وMoodle XML (shortanswer, numerical, essay) وCSV (كل الأنواع الخمسة). الترتيب وملء الفراغات في CSV فقط.

## حدود
- حدود عدد كلمات المقال إرشادية في الواجهة (الخادم يحدّ بـ٢٠٠٠٠ حرف).
- التصحيح الآلي للنص يعتمد توحيدًا لغويًا بسيطًا، لا مطابقة تقريبية (أخطاء الإملاء تُعدّ خطأ).
- لا إشعار تلقائي للمتدرب عند اكتمال التصحيح بعد (مرحلة الإشعارات).
